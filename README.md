Why do you want to build this project?

I want to build this project to make it easier for students to keep track of their assignments and deadlines. It will provide a simple platform where students can organize their academic tasks and monitor their progress.

What problem will this project solve and who is it for?

The project will help students avoid forgetting assignments and missing deadlines by keeping all their tasks organized in one place. It is mainly designed for students and can also be useful for teachers to create and manage assignments.

List 5 core features your project must have (MVP):

Student registration and login

Add and manage assignments/tasks

Set assignment deadlines

Mark tasks as completed or pending

View upcoming and completed assignments
